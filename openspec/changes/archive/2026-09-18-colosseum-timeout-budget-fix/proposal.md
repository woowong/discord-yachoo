# Proposal: Colosseum Execution Budget & Timeout Fix

## 1. Problem Statement
최근 추가된 4대 막 2단계 롤링 연출(각 막당 주사위 롤링 서스펜스 3.0초 + 득점 확정 3.5초 = 총 26초 슬립)과 Discord API 호출 왕복 지연(8회 이상 * 약 0.4초 = ~3.2초), 초기 결투 데이터 페칭(~1.5초)의 합산 실행 시간이 **Cloudflare Worker `ctx.waitUntil`의 30초 강제 종료 하드 리밋**을 초과하여 제4막 집계 단계("최종 결과 및 ELO 정산을 집계 중입니다...") 직후 Worker가 런타임에 의해 강제 종료되는 현상이 발생했습니다. 이로 인해 최종 결과 및 ELO 정산 발표 임베드가 Discord 메시지로 전달되지 못하고 메시지가 멈추었습니다.

## 2. Proposed Solution
1. **타임아웃 안전 예산 재설계 (총 슬립 17.0초, 전체 소요 시간 약 21~22초)**:
   - 각 막의 Stage A (롤링 GIF 및 컵 셰이킹): 2.0초
   - Acts 1~3의 Stage B (득점 확정 및 도파민 대사): 2.5초
   - Act 4의 Stage B (최종 12라운드 직후 정산 전환 대기): 1.5초 (이미 "집계 중입니다..."를 띄운 직후이므로 1.5초의 짧은 숨고르기 후 즉시 최종 결과 발표)
   - 총 슬립 시간: 2.0 * 4 + 2.5 * 3 + 1.5 = **17.0초**. API 오버헤드(~4.5초) 포함 총 **~21.5초**로 30초 리밋 대비 **8.5초 이상의 충분한 안전 버퍼**를 확보합니다.
2. **에러 로깅 및 관측성 강화**:
   - `editMessage` 실패 시 에러를 침묵(`Effect.void`)하지 않고 에러 콘솔 로그를 남겨 디버깅 가능하도록 보강합니다.
3. **단위 테스트 업데이트**:
   - Vitest 테스트의 editMessage 호출 검증 및 슬립 시간/타임아웃 검증을 동기화합니다.
