# Proposal: Colosseum Every Round Live Broadcast

## Why
현재 초파리 콜로세움 관전은 12라운드 중 4개 라운드(R03, R06, R09, R12)만 스킵하여 요약 렌더링하고 있어, 인간 대 인간이나 인간 대 초파리 게임처럼 매 턴마다 어떤 주사위가 나오고 어떤 점수가 채워지는지 한 턴 한 턴 따라가는 박진감과 몰입도가 떨어집니다. 사용자는 턴을 건너뛰지 않고 1라운드부터 12라운드까지 모든 라운드의 플레이 과정(주사위, 락, 선택 족보, 누적 스코어보드, 도파민 대사)이 차례대로 화면에 그려지기를 원합니다.

## What Changes
1. **12라운드 전 라운드 순차 렌더링 (`serializeColosseumRound`)**:
   - 기존 4대 막(R03, R06, R09, R12) 스킵 방식에서 탈피하여, **Round 1부터 Round 12까지 12개 라운드 전 과정을 1라운드씩 순차적으로 Discord 메시지에 렌더링**합니다.
   - 각 라운드마다 양 검투사의 최종 주사위 이모지, 락(`🔒`), 채택한 족보와 획득 점수, 실시간 도파민 수치와 도발 대사, 그리고 해당 라운드까지 채워진 **전체 ASCII 스코어보드(상단 합계/63, 보너스, 족보별 점수)**가 실시간으로 갱신됩니다.
2. **Discord API 및 Cloudflare Workers 실행 시간 최적화**:
   - 오프닝(주사위 컵 셰이킹 & 롤링 애니메이션): 1.5초
   - Round 1 ~ 11: 라운드당 1.2초 지연 (ASCII 점수표가 한 줄씩 채워지는 긴장감 전달)
   - Round 12: 1.2초 지연 후 최종 집계 단계 진입
   - 최종 결과 & ELO 정산 발표: 1.0초 후 전환
   - 총 슬립 시간: 1.5s + (12 * 1.2s) = 15.9초. HTTP 요청 지연(~4.5s) 및 초기 페칭(~1.0s) 포함 총 실행 시간 **~21.5초**로 Cloudflare Worker 30초 한도 및 Discord API 편집 레이트 리밋(5req/5s)을 완벽히 준수합니다.
3. **단위 및 워크플로 테스트 업데이트**:
   - 12개 라운드 순차 렌더링에 맞추어 `editMessage` 호출 횟수(오프닝 1 + 라운드 12 + 최종결과 1 = 총 14회) 및 직렬화 테스트를 동기화합니다.
