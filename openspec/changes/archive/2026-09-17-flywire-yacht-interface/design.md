## Context

Phase 1에서 Mushroom Body(1,575개 뉴런, 27,744개 시냅스) 서브그래프를 캐싱하고 LIF SNN forward pass를 0.59ms 안에 실행할 수 있음을 검증했습니다.
Phase 2의 핵심 과제는 **Yacht 게임 엔진과 SNN 사이의 양방향 인터페이스(Sensory Encoder & Motor Decoder)**를 정의하고, 초파리 에이전트가 단독으로 12라운드 게임을 규칙에 맞게 완주할 수 있음을 입증하는 것입니다.

## Goals / Non-Goals

**Goals:**
- Yacht 규칙을 100% 반영하는 Python 환경 내 경량 게임 엔진(`yacht_env.py`) 구현.
- 게임 상태(주사위 눈, 롤링 카운트, 점수판) $\rightarrow$ 50개 투사 뉴런(PN) 전류 주입 인코더 구현.
- 24개 MBON 뉴런의 스파이크 빈도 $\rightarrow$ 주사위 홀드 마스크(5개 불리언) 및 카테고리 선택(12개 중 유효 1개) 디코더 구현.
- 1게임(12턴) 및 다중 게임(20~50게임) 자율 완주 벤치마크 러너 구현.

**Non-Goals:**
- 시냅스 가중치 학습/최적화 (Phase 3에서 진행). Phase 2는 초기 배선 상태에서 유효한 의사결정 파이프라인의 완성도를 검증.
- Discord 봇 통신 브릿지.

## Decisions

### 1. 입력 감각 인코딩 구조 (50 Projection Neurons)
- **주사위 표현 (30 뉴런)**: 5개 주사위 슬롯 x 6개 눈 값 = 30 뉴런 (One-hot mapping).
  - 예: 주사위 [3, 3, 4, 5, 6] $\rightarrow$ Slot 0 Face 3, Slot 1 Face 3 등에 전류 주입.
- **리롤 횟수 (3 뉴런)**: 현재 롤링 횟수(0, 1, 2)를 각각 1개 뉴런으로 인코딩.
- **잔여 카테고리 (12 뉴런)**: 아직 선택되지 않은 카테고리에 상시 기저 전류를 주입하여 선택 가능성을 활성화.
- **예비 (5 뉴런)**: 상단 점수 보너스 근접도(0~63 정규화) 또는 글로벌 턴 번호.

### 2. 출력 결정 디코딩 구조 (24 MBONs)
- MBON #0 ~ #4 (5 뉴런): 주사위 5개 각각의 Hold/Reroll 결정. 발화 수 > 임계치 또는 중간값 이상이면 Hold (유지).
- MBON #5 ~ #16 (12 뉴런): 12개 스코어 카테고리(Aces, Deuces, ..., Yacht)에 1:1 매핑.
  - 마스킹 기법: 이미 채워진 카테고리는 발화 수와 무관하게 선택 후보에서 제외하고, 잔여 카테고리 중 발화 수가 가장 높은 카테고리를 선택.
- MBON #17 ~ #23 (7 뉴런): 예비/내부 상태.

### 3. 독립 Python 게임 엔진 (`yacht_env.py`)
- TypeScript `src/domain/score.ts` 및 `src/domain/game.ts`의 채점 룰과 100% 동일하게 구현하여, TS 엔진과 완벽한 정합성을 유지.

## Risks / Trade-offs

- **[초기 가중치의 무작위성]** → 학습 전 단계이므로 초파리 뇌는 전략적으로 최적이 아닌 다소 엉뚱한 결정을 내릴 수 있음. 하지만 이것은 정상적인 현상이며, "규칙 위반 없이 유효한 액션을 도출하여 12턴 게임을 끝까지 완주하는가"가 본 단계의 성공 기준임.
- **[침묵 상태(No Spikes) 대비]** → 입력 신호가 약해 MBON에서 스파이크가 1개도 나오지 않을 경우, 폴백(기본 1번 주사위 굴리기, 잔여 카테고리 중 첫 번째 선택)으로 안전하게 게임이 진행되도록 처리.
