## Context

현재 초파리 콜로세움 관전은 단 2단계(R06, R12)로만 압축되어 있고 지연 시간도 3초씩 총 6초에 불과하여 관전의 박진감이 떨어집니다. 또한 일반 게임 보드처럼 카테고리별 점수판이나 주사위 롤 과정이 표시되지 않으며, 대사 역시 다소 점잖게 작성되어 있습니다.

## Goals / Non-Goals

**Goals:**
- **일반 게임 수준의 전체 점수판(ASCII Table) 및 주사위/락 그래픽**:
  - 두 검투사의 Aces ~ Yacht, Subtotal, Bonus, Total 점수표를 실시간 반영.
  - 현재 턴 선수의 주사위 이모지(`⚀~⚅`)와 락 상태(`🔒 ▫️`)를 직관적으로 렌더링.
- **다단계 드라마틱 챕터 진행 및 긴장감 지연**:
  - 총 12라운드를 6개 주요 챕터(R1-2, R3-4, R5-6, R7-8, R9-10, R11-12)로 나누어 각 챕터당 2.5초 지연(총 15초 내외)을 주며 순차 편집.
  - Cloudflare Worker `ctx.waitUntil` 최대 실행 시간(30초) 및 Discord 메시지 수정 레이트 리밋(초당 1회)을 철저히 준수.
- **키치하고 매운맛 B급 밈 대사**:
  - 도파민 분비량, 롤 상황(대박, 억까, 상단 보너스 계산, 직진 폭주 등)에 따라 유머러스하고 매운 인터넷 밈 대사 탑재.

**Non-Goals:**
- Discord 채널에 개별 메시지를 12개씩 쏘는 행위 (채널 도배 방지를 위해 단일 메시지 연속 `editMessage` 유지).
- 실시간 웹소켓 연결 (Discord Interaction + Cloudflare Worker 비동기 백그라운드 태스크 아키텍처 유지).

## Decisions

1. **Python 시뮬레이터 텔레메트리 확장 (`simulate_colosseum_duel`)**:
   - 기존: 라운드별 최종 점수, 최종 주사위만 반환.
   - 변경: 각 라운드마다 3회 롤 상세 내역 (`rolls: [{ dice, holds }]`) 및 해당 라운드 종료 시점의 누적 점수판 스냅샷 (`scoreBoard: { Aces: 3, ... }`)을 포함하여 반환.
   - 이유: 클라이언트(Worker)가 별도 복원 계산 없이 즉시 일반 게임과 동일한 ASCII 점수판을 렌더링할 수 있음.

2. **관전 챕터 분할 (6 Chapters + 1 Result)**:
   - Ch 1 (R02 종료): 초반 탐색전 (Opening clash)
   - Ch 2 (R04 종료): 상단 족보 기선제압
   - Ch 3 (R06 종료): 전반전 중간 점검 & 선두 쟁탈
   - Ch 4 (R08 종료): 상단 보너스(63점) 사수전
   - Ch 5 (R10 종료): 클러치 족보(야추/라스트) 도박
   - Ch 6 (R12 종료): 최종 라운드 혈투
   - Ch 7 (Final): 정산 및 승자 발표
   - 타이밍: 각 챕터 사이 2.5초 지연 (`Effect.sleep("2.5 seconds")`). 총 지연 약 15~17초.

3. **키치한 페르소나 대사 엔진 개편**:
   - `Jackpot`: 도파민 풀악셀, 인생 한 방, 한강물 드립, 흑우 조롱.
   - `Newton`: 수학적 참교육, 지능 이슈, 0.1mm³ 뇌용적 디스, 연산 오류 절규.
   - `Speeder`: 고민은 사치, 비둘기 밥, 풀악셀, 굼벵이 조롱.
   - `Chimera`: 양자 얽힘 주사위, 코스믹 호러, 뉴런 비트코인 채굴, 은하계 교신.

## Risks / Trade-offs

- **[Risk] Cloudflare Worker background execution timeout**
  - Worker `ctx.waitUntil`은 30초 내에 완료되어야 안전합니다.
  - Mitigation: 6개 챕터 * 2.5초 = 15초, 네트워크 왕복 포함 약 18초로 30초 한도 내에서 여유 있게 완료되도록 설계.
- **[Risk] Discord API Rate Limit (edit message)**
  - Discord는 동일 메시지에 대해 5초당 5회 이상의 수정을 제한합니다.
  - Mitigation: 2.5초 간격으로 수정하므로 초당 0.4회 수정으로 레이트 리밋에 걸리지 않습니다.
